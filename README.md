# Global Financial Markets Dashboard

An end-to-end Data Analytics project demonstrating:

- REST APIs
- ETL Pipelines
- Python
- pandas
- SQLite
- SQL
- Tableau
- GitHub

## Project Objective

Build an automated ETL pipeline that collects financial market data from public APIs, transforms it into analysis-ready datasets, stores it in SQLite, and visualizes insights through an interactive Tableau dashboard.

The dashboard will help answer questions such as:

- How did the S&P 500 perform today?
- Is Bitcoin outperforming stocks?
- Which asset had the highest daily return?
- How volatile is gold compared to equities?
- How correlated are crypto and stock markets?
